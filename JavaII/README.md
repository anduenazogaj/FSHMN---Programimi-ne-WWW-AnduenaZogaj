# Pikënisja — Java II

Lexo ../README.md. Krijo skedarët e kërkuar në folderin tënd JavaII; ky folder përmban vetëm skeletin ose të dhënat hyrëse. 

Shëno para kodimit: hyrjet, daljet, një rast normal dhe dy raste kufitare.

## Analiza para kodimit

### Hyrjet
- Titulli i faqes: "Muzeu i sendeve"
- Tre sende: Çelësi, Filxhani dhe Bileta
- Fotografitë SVG të sendeve
- Titulli dhe përshkrimi i secilit send
- Data e ekspozitës

### Daljet
- Një faqe web me titullin "Muzeu i sendeve"
- Navigimi për Çelësi, Filxhani dhe Bileta
- Tre karta me informacionet përkatëse
- Fotografia e secilit send
- Përshkrimi i secilit send
- Pjesa "Historia e fshehur"

### Rast normal
Faqja hapet në mënyrë normale dhe shfaq të tre sendet me fotografinë,
titullin dhe përshkrimin e tyre.

### Rast kufitar 1
Faqja hapet në një ekran të vogël, si telefon, dhe përmbajtja duhet
të përshtatet me madhësinë e ekranit.

### Rast kufitar 2
Përdoruesi klikon në lidhjet e navigimit për Çelësi, Filxhani ose Bileta
dhe navigimi duhet të funksionojë siç është paraparë.
